# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it in private:

1. Use GitHub "Report a vulnerability" in the Security tab of this repository (private security advisory).
2. Or send an email to the maintainers. The address is listed in `MAINTAINERS` when that file is added.

Please include:

- What the problem is and which module it is in (`broker`, `controlplane`, `dst`, `shared`).
- Steps to reproduce, or a small test that shows it.
- The version or commit you tested.

## What to expect

- We will reply within 5 working days to say we got your report.
- We will tell you if we accept it as a vulnerability, and share a plan and a rough date for the fix.
- We will credit you in the release notes if you want, after the fix is released.

Please give us time to fix the problem before you share it in public.

## Supported versions

The project is before 1.0. Only the latest release and the `main` branch get security fixes.
